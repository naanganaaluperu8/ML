To implement Naive Bayes classifier for the Iris dataset and evaluate its performance

AIM

To implement a Python program to classify Iris flower species using the Naive Bayes algorithm and evaluate its performance.

PROGRAM DESCRIPTION

Naive Bayes is a supervised machine learning algorithm based on Bayes' Theorem and is widely used for classification tasks. It assumes that all input features are independent, which makes the method simple and efficient. Bayes' Theorem is given by P(C|X) = [P(X|C) * P(C)] / P(X) where P(C|X) is Posterior probability, P(X|C) is Likelihood, P(C) is Prior probability, P(X) is Evidence. Gaussian Naive Bayes is used, which assumes that the features follow a normal distribution. The model is trained using the fit() function and predictions are made using the predict() function. The performance is evaluated using accuracy score and classification report.

ALGORITHM

  1. Start.
  2. Import the required Python libraries for data handling, visualization, and machine learning.
  3. Load the Iris dataset from sklearn.datasets.
  4. Convert the dataset into a pandas DataFrame for easier analysis.
  5. Separate the dataset into input features (X) and target variable (y) representing flower species.
  6. Split the dataset into training data (70%) and testing data (30%).
  7. Import the Gaussian Naive Bayes classifier.
  8. Initialize the Naive Bayes model.
  9. Train the model using the training dataset.
  10. Visualize feature relationships using a pair plot.
  11. Predict the class labels using the testing dataset.
  12. Evaluate the model performance using Accuracy Score and Classification Report.
  13. Predict the species for a new sample input.
  14. Display the results and graphs.
  15. Stop.

PROGRAM

# -----------------------------
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.naive_bayes import GaussianNB
from sklearn.metrics import accuracy_score, classification_report
import seaborn as sns
import matplotlib.pyplot as plt

# Load dataset as DataFrame
data = load_iris(as_frame=True)
df = data.frame

# Features and target
X = df.drop('target', axis=1)
y = df['target']

# Split
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42
)

# Train model
model = GaussianNB()
model.fit(X_train, y_train)

# Predict
y_pred = model.predict(X_test)

# Accuracy
print("Accuracy:", accuracy_score(y_test, y_pred))

# Classification report
print(classification_report(
    y_test,
    y_pred,
    target_names=data.target_names
))

# Add species names for graph
df['species'] = df['target'].map({
    0: data.target_names[0],
    1: data.target_names[1],
    2: data.target_names[2]
})

# Pairplot
sns.pairplot(df, hue="species")
plt.show()

# Test sample
new_sample = [[5.1, 3.5, 1.4, 0.2]]
prediction = model.predict(new_sample)

print("Predicted class:",
      data.target_names[prediction][0])
