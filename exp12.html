To implement an efficient Multilayer Perceptron model using TF-IDF and SVD.

AIM

To implement an efficient Multilayer Perceptron (MLP) model for classifying the 20 Newsgroups dataset using TF-IDF vectorization and TruncatedSVD for dimensionality reduction.

ALGORITHM

  1. Import necessary libraries.
  2. Load the 20 Newsgroups dataset.
  3. Apply TF-IDF vectorization with limited features (e.g., max_features=5000).
  4. Perform dimensionality reduction using TruncatedSVD.
  5. Visualize the 2D SVD transformed data.
  6. Split the vectorized data into training and testing sets.
  7. Train the MLPClassifier model.
  8. Predict on the test set.
  9. Evaluate the model using accuracy score, classification report, and confusion matrix.
  10. Display the confusion matrix heatmap.

SOURCE CODE

from sklearn.datasets import fetch_20newsgroups
from sklearn.metrics import accuracy_score, classification_report, confusion_matrix
from sklearn.model_selection import train_test_split
from sklearn.neural_network import MLPClassifier
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.decomposition import TruncatedSVD
import matplotlib.pyplot as plt
import seaborn as sns

print("Step 1: Loading dataset...")
data = fetch_20newsgroups()

x = data.data
y = data.target
print("Step 2: Data ready")

# ✅ Limit features (VERY IMPORTANT)
print("Step 3: TF-IDF vectorization...")
vectorizer = TfidfVectorizer(max_features=5000)
x_vec = vectorizer.fit_transform(x)
print("TF-IDF done")

# ✅ Use TruncatedSVD instead of PCA (works with sparse)
print("Step 4: Dimensionality reduction...")
svd = TruncatedSVD(n_components=2)
x_svd = svd.fit_transform(x_vec)
print("SVD done")

# Visualization
plt.scatter(x_svd[:,0], x_svd[:,1])
plt.title("2D Visualization (SVD)")
plt.show()

# ✅ Split vectorized data
print("Step 5: Splitting data...")
x_train, x_test, y_train, y_test = train_test_split(
    x_vec, y, test_size=0.2, random_state=42
)

# ✅ Train model with progress
print("Step 6: Training model...")
model = MLPClassifier(max_iter=100, verbose=True)
model.fit(x_train, y_train)

# Predict
print("Step 7: Predicting...")
y_pred = model.predict(x_test)

# Evaluation
print("Step 8: Evaluating...")
print("Accuracy:", accuracy_score(y_test, y_pred))
print("\nClassification Report:\n", classification_report(y_test, y_pred))

# Confusion matrix
cm = confusion_matrix(y_test, y_pred)
sns.heatmap(cm, annot=True, fmt='d')
plt.title("Confusion Matrix")
plt.show()

print("✅ Completed successfully")
